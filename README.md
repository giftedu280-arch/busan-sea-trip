# 마! 어데가노 머먹노?

외국인 관광객이 부산에서 무엇을 할지 쉽게 고를 수 있도록 만든 수업용 웹 앱 시제품입니다.

## 실행 방법

1. 이 폴더의 `index.html` 파일을 더블클릭합니다.
2. 언어를 선택하면 웹페이지 전체 문구가 한국어, 일본어, 중국어 또는 영어로 즉시 바뀝니다.
3. 추천 종류를 선택합니다.
4. 맞춤 질문에 답하면 관광지 또는 맛집 세 곳을 확인할 수 있습니다.
5. 어떤 추천 종류를 선택해도 결과 아래에 `AI가 추천해주는 로드맵`이 표시됩니다.
6. 관광지·맛집 추천은 관광지 두 곳과 맛집 한 곳을 함께 보여줍니다.

인터넷 연결이나 별도 설치, 로그인, 데이터베이스가 필요하지 않습니다. 단, 결과의 **지도에서 확인하기** 기능은 인터넷 연결이 필요합니다.

## 파일 설명

- `index.html`: 화면의 구조와 문구
- `styles.css`: 부산 바다 분위기의 디자인과 반응형 화면
- `app.js`: 질문 화면, 추천 점수 계산, 결과와 로드맵 생성

## 수정하기 쉬운 부분

추천 장소를 바꾸려면 관광지는 `attraction-data.js`, 맛집은 `app.js` 위쪽의 `foodData`를 수정합니다. 각 장소의 `tags`가 사용자의 답과 많이 일치할수록 추천 순위가 높아집니다.

현재 관광지 32곳은 `attraction-data.js`에 지역, 추천 MBTI, 설명, 리뷰 형태로 정리되어 있습니다. 지정된 MBTI가 정확히 일치할수록 추천 점수가 크게 높아지며 관광지 추천과 관광지·맛집 추천에 함께 사용됩니다.

점심·저녁 추천 메뉴와 음식 태그는 `food-data.js`에 정리되어 있습니다. 맵기 허용 수준, 날것 섭취 여부, 한국 향토 음식 도전 여부, 볶음·구이·국물 선호를 점수에 반영하며 음식 추천에는 MBTI를 사용하지 않습니다.

음식 메뉴에는 제공 가능한 지역 태그가 포함되어 있습니다. 현재 위치에 등록되지 않은 메뉴는 추천 후보에서 먼저 제외되며, 지도 검색도 선택한 현재 위치와 메뉴를 함께 검색합니다.

첫 화면에서 동행 유형과 나이대를 하나씩 선택하고, 볼거리·맛집·뷰&카페·체험은 복수 선택할 수 있습니다. 선택한 모든 분야에서 각각 추천 3개를 보여줍니다. 카페와 체험 데이터는 `leisure-data.js`에 정리되어 있습니다.

부산의 맛 추천은 현재 지역과 음식 취향 조건을 충족하는 후보를 평점순으로 1~3위까지 표시합니다. AI 로드맵은 추천 세 곳을 오전 8시, 오후 1시, 오후 6시에 나누어 보여줍니다.

이 버전은 한 시간 안에 설명하고 수정할 수 있도록 실제 인공지능 서버 대신 브라우저 안에서 작동하는 가중치 기반 맞춤 로직을 사용합니다. 나중에 실제 지도나 인공지능 응용 프로그램 인터페이스를 붙이려면 추천 결과를 만드는 `getRecommendations` 함수를 서버 호출로 교체하면 됩니다.

## 주의

맛집과 관광지 정보는 수업용 예시 데이터입니다. 실제 방문 전 지도에서 최신 위치와 운영 정보를 확인해야 합니다.
